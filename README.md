## Usage

### 1. Clone repository

```bash
git clone https://github.com/tranaiminhthuyy-blip/Test2.git
```

### 2. Download datasets

Download all CSV files from the Google Drive folder.

### 3. Place files

Put all CSV files in the same directory as `load_data.py`.

### 4. Run

```bash
python load_data.py
```
